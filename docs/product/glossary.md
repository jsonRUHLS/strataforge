# Domain Glossary

> Status: In progress

## Architecture layer

A logical concern in an end-to-end software solution. Initial StrataForge layers are presentation, application, domain, data, integration, and infrastructure.

## Atlas

A curated, explainable architecture blueprint for a scenario or implementation goal.

## Blueprint

A structured solution plan containing selected technologies, architecture layers, rationale, alternatives, compatibility notes, integration boundaries, and implementation guidance.

## Composer

The StrataForge capability for assembling a custom solution blueprint by selecting technologies layer by layer.

## Compatibility

The documented relationship between two technologies or architectural choices. A relationship may be recommended, supported, supported with an adapter, subject to a caveat, not recommended, or incompatible.

## Core language

A programming language used as the primary implementation language for a code example or technology choice.

## Domain event

A versioned record that an important business fact occurred, such as a blueprint being created or a technology compatibility relationship being updated.

## Integration boundary

The explicit point where one application component, technology, service, or external system communicates with another.

## Pattern

A reusable solution structure for a recurring software design problem.

## Scenario

A concrete implementation context in which patterns and technology choices can be evaluated, such as integrating a third-party task API.

## Technology

A software language, framework, library, runtime, database, message broker, cloud service, observability tool, or related implementation choice.

## Variant

A pattern implementation adapted for a particular language, framework, platform, runtime, or technology stack.
